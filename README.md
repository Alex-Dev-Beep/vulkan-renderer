# Vulkan Renderer

### A 3D renderer built with Vulkan.

#### Requirements:
- CMake (build system generator)
- GCC (C++ compiler)
- clangd (language server)
- Git

All project dependencies (such as GLM, GLFW, and stb_image) are included in the repository.

#### Build Instructions:

##### Windows:
1. At the root of the project, run 'build_and_run_windows.bat'.

##### Linux:
1. At the root of the project, run 'chmod +x build_and_run_linux.sh'.
2. Run './build_and_run_linux.sh'.

#### Run Instructions:

##### Windows:
1. Double-click the executable or run it from the Command Prompt:
   'renderer.exe'
2. Alternatively, run it from PowerShell:
   '.\renderer.exe'

##### Linux:
1. Navigate to the directory containing the executable.
2. Run 'chmod +x renderer'.
3. And, now you can run './renderer' whenever you want!

##### Mac:
1. Navigate to the directory containing the executable.
2. Run 'chmod +x renderer'.
3. And, now you can run './renderer'!
