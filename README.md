# A 3D renderer build with Vulkan Renderer.

#### Compile Instructions:
##### - Windows:
###### 1. At the root of the project, run: build_and_run_windows.bat

##### - Linux:
###### 1. At the root of the project, run: chmod +x build_and_run_linux.sh

#### Run Instructions:
##### - Windows:
###### 1. Simply double click the executable or run in the command prompt: renderer.exe
###### 2. Or, in the powershell, you can run: .\renderer.exe

##### - Linux:
###### 1. Run from the command prompt in the path of the executable: chmod +x ./renderer
