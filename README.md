# Vulkan Renderer

### A 3D renderer built with Vulkan.

<img width="849" height="705" alt="image" src="https://github.com/user-attachments/assets/7a48a9c6-6f6a-4b86-8b6c-1eeadb770417" />

#### Requirements:
- CMake (build system generator)
- GCC (C++ compiler)
- clangd (language server)
- Git

All project dependencies (such as GLM, GLFW, and stb_image) are included in the repository.

#### Run Instructions (if you have a .zip from the releases):

##### Windows:

1. Simply double-click the executable.

#### Build Instructions:

##### Windows:
1. At the root of the project, run 'build_windows.bat'.

##### Linux:
1. At the root of the project, run 'chmod +x build_unix.sh'.
2. Run './build_unix.sh'.

#### Run Instructions:

##### Windows:
1. Double-click the executable or run it from the Command Prompt:
   'renderer.exe'
2. Alternatively, run it from PowerShell:
   '.\renderer.exe'

##### Linux:
1. Navigate to the directory containing the executable.
2. Run 'chmod +x renderer'.
3. And, now you can run './renderer' whenever you want!

##### Mac:
1. Navigate to the directory containing the executable.
2. Run 'chmod +x renderer'.
3. And, now you can run './renderer'!
